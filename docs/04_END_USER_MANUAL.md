# PaceLab V6.4 — คู่มือการใช้งาน (End-user Manual)

> **V6.4 authority note:** For mode-specific announcements, PNG exports, cadence/elevation and analytics, see the final V6.3/V6.4 sections in this document. These take precedence over historical V6.2 statements.


> คู่มือนี้อธิบาย **พฤติกรรมที่ออกแบบไว้** ของ PaceLab V6.4 แอปยังไม่ได้ Implement ดังนั้นชื่อเมนู/หน้าจอจริงอาจปรับตามผล UX และการทดสอบก่อนปล่อยใช้งาน

## 1. PaceLab คืออะไร

PaceLab เป็นแอปวิ่งสำหรับผู้ที่ต้องการเก็บ **เวลา ระยะทาง Pace** และทำ **Interval Training แบบละเอียด** โดยใช้โทรศัพท์ ไม่จำเป็นต้องมีนาฬิกา GPS ออกแบบให้ใช้กับกลุ่มนักกีฬา 1–10 คน ทั้งการวิ่งถนนและสนามลู่

มี 2 โหมด:

- **Free Run:** วัน Easy / Recovery / Long Run — เปิดแล้วเริ่มวิ่งได้ ไม่ต้องสร้างแผน
- **Structured Workout:** วัน Interval / Threshold / Tempo / VO₂max — เลือกหรือสร้างคอร์ทก่อน แล้วดู Preview Timeline ก่อน Start

## 2. ติดตั้งและเข้าสู่ระบบ

### Android

1. รับไฟล์ APK จากผู้พัฒนาหรือช่องทางกลุ่มที่เชื่อถือได้
2. ดาวน์โหลดและอนุญาตการติดตั้งจากแหล่งนั้นเฉพาะเมื่อจำเป็น
3. ติดตั้งและเปิด PaceLab
4. เลือก **Continue with Google** หรือ Facebook เมื่อระบบรองรับ
5. ยืนยันการเข้าสู่ระบบตามหน้าของผู้ให้บริการ
6. ตรวจสอบชื่อโปรไฟล์และหน่วยที่ต้องการ

### iPhone

เมื่อมีการแจก Native iOS ผ่านช่องทางที่ถูกต้องแล้ว ให้ติดตั้งตามคำเชิญ TestFlight/ช่องทางที่ผู้พัฒนาระบุ ไม่สามารถนำไฟล์ Android APK ไปติดตั้งบน iPhone ได้ ขณะโครงการยังเป็น Android-first จึงยังไม่ถือว่าแจก Native iOS ฟรีได้

### สิทธิ์ตำแหน่งและเสียง

อนุญาตตำแหน่งที่แม่นยำเมื่อประสงค์จะเก็บ GPS และอนุญาต Background Location ตามคำอธิบายของแอป/ระบบปฏิบัติการเมื่อจำเป็น หากไม่ให้สิทธิ์ GPS ใช้ **Time-only** ได้สำหรับงานจับเวลา แต่จะไม่มี Distance/Current Pace จริง เสียงแจ้งเตือนขึ้นกับ Media Volume และการเชื่อมต่อหูฟัง

## 3. หน้า Home

หน้าหลักควรมีสถานะ GPS และทางเลือก:

- **Start Free Run:** สำหรับวิ่งทั่วไป ไม่มีแผน
- **Structured Workout:** เลือก/สร้าง Interval
- **Activities:** ประวัติผลการวิ่ง
- **Settings:** หน่วย, Countdown, เสียง, แก้ Dashboard, บัญชี

สถานะ GPS เช่น Good / Fair / Poor เป็นตัวช่วยตัดสินใจ ไม่ใช่การรับประกันว่าตำแหน่งถูกต้องเสมอ

## 4. ใช้ Free Run สำหรับ Easy/Recovery/Long

1. เปิดแอปและออกไปยังพื้นที่ที่รับ GPS ได้ดี
2. ตรวจสอบ GPS Status; หากยังไม่พร้อมสามารถรอหรือเลือก Time-only (เมื่อระบบเสนอ)
3. กด **Start Free Run**
4. ถ้าตั้ง Pre-workout Countdown เป็น On ระบบจะนับ **5,4,3,2,1,GO** ก่อนเริ่มจับเวลาจริง
5. ระหว่างวิ่งมีค่าเริ่มต้น 3 ช่องใหญ่: **Duration / Distance / Current Pace**
6. ใช้ **Pause** เมื่อต้องการหยุดชั่วคราว และ **Resume** เมื่อวิ่งต่อ
7. เมื่อจบ กด **Finish**, ยืนยัน และตรวจสอบ Summary
8. เลือกประเภทกิจกรรม Easy / Recovery / Long / General แล้วบันทึก
9. แอปเก็บข้อมูลในเครื่องก่อน และ Sync ขึ้น Cloud เมื่อพร้อม

**ข้อควรรู้:** ระยะทางมาจาก GPS จึงคลาดเคลื่อนได้ โดยเฉพาะสนามโค้ง/ในอาคาร/ตึกสูง ถ้าข้อมูลไม่พร้อม Pace จะแสดง `--:--` ไม่ใช่ `0:00`

## 5. สร้างคอร์ท Interval ด้วยตัวเอง

สมมติได้รับตารางในแชทว่า: **Warm-up 10 นาที → 3 นาที × 6 พัก Jog 2 นาที → Cool-down 10 นาที**

1. เปิด **Workouts → Create Workout**
2. ตั้งชื่อ เช่น `VO2max 6×3min`
3. เพิ่ม **Warm-up** แบบ Time **10:00**
4. เพิ่ม Repeat Block: Work = **3:00**, Repetitions = **6**
5. ตั้ง **Recovery = 2:00** ระหว่าง Repetitions
6. เพิ่ม **Cool-down** แบบ Time **10:00**
7. เลือก Pace Target (ถ้าต้องการ), หากไม่ได้กำหนดระบบไม่สร้างค่าระยะเป้าหมายให้เอง
8. กด Save Template เพื่อใช้งานครั้งหน้า

สำหรับคอร์ท 400m × 10 ให้เลือก Target Type = Distance และตั้ง 400m; ระบบจบ Step ด้วยระยะ GPS ที่ตรวจสอบแล้ว แต่อาจมีความคลาดเคลื่อนจาก GPS

## 6. ตรวจสอบ Workout Preview Timeline (บังคับก่อน Interval)

เมื่อเลือกคอร์ทแล้ว แอปแสดงลำดับ:

```text
Warm-up     10:00
Work 1       3:00
Recovery 1   2:00
Work 2       3:00
Recovery 2   2:00
Work 3       3:00
Recovery 3   2:00
Work 4       3:00
Recovery 4   2:00
Work 5       3:00
Recovery 5   2:00
Work 6       3:00
Cool-down   10:00
-------------------
Total       48:00
```

ตรวจว่ามี Work **6** ช่วง, Recovery **5** ช่วง, Warm-up/Cool-down เปิด, รวม **48:00** และค่า Pre-workout Countdown **5 วินาทีที่ไม่รวมในเวลา 48 นาที** นอกจากนี้ตรวจสถานะเสียงก่อนเริ่ม/ก่อนจบ/ก่อนเริ่มเซ็ตถัดไป จากนั้นกด **Start Workout** หรือ **Edit** หากพบคอร์ทผิด

## 7. หน้าระหว่าง Interval

แสดง **Set 3/6**, สถานะ **WORK** หรือ **RECOVERY** และช่องหลักตามค่าเริ่มต้น:

| ช่อง | ความหมาย |
|---|---|
| Set Remaining | เวลาคงเหลือของเซ็ตแบบ Time-based |
| Set/Lap Elapsed | เวลาที่ใช้ไปในเซ็ตปัจจุบัน |
| Set Distance | ระยะที่วิ่งไปแล้วเฉพาะ Step ปัจจุบัน |
| Target Distance | ระยะเป้าหมาย **เฉพาะเมื่อแผนระบุไว้** |
| Current Pace | ค่าความเร็วเฉลี่ยในรูปเวลาต่อกิโลเมตร/ไมล์จากข้อมูลล่าสุด |

หาก Work กำหนดเป็น **3 นาทีเท่านั้น** ช่องระยะอาจแสดง `420m / —` และไม่แสดง `420m / 750m` เพราะไม่มีระยะเป้าหมายในแผน ผู้ใช้สามารถเปลี่ยน Metrics ได้ตาม Dashboard Layout แต่ Work/Recovery และ Set # ต้องเห็นชัด

### เสียง Countdown แบบ Unified V6.2

ค่ามาตรฐานคือ **5 วินาทีเท่ากันทั้งสามเหตุการณ์**:

- ก่อนเริ่ม Workout: `5 4 3 2 1 GO`
- ก่อนจบ Work: `5 4 3 2 1 END`
- ก่อนเริ่ม Work ถัดไป (ช่วงท้าย Recovery): `5 4 3 2 1 GO`

Countdown สองแบบหลัง **อยู่ภายในเวลาเซ็ต/Recovery ที่ตั้งไว้** ไม่เพิ่มเวลาซ้อม หลัง Work 6 จะเข้า Cool-down เลยโดยไม่มี Recovery อีกช่วง สำหรับ Distance-based Step อาจใช้เสียงระยะทางคงเหลือแทนการนับวินาทีที่คาดเดาไม่ได้

## 8. ตั้งค่า Countdown

ไป **Settings → Workout & Audio → Countdown** แล้วเลือก Duration: **3 / 5 / 10 วินาที** ค่าเริ่มต้น **5 วินาที**

มีปุ่มเปิด/ปิดแยก 3 ประเภท:

1. Countdown Before Workout — ค่าเริ่มต้น On
2. Countdown Before Set Ends — ค่าเริ่มต้น On
3. Countdown Before Next Set — ค่าเริ่มต้น On

เมื่อเปลี่ยน Duration เป็น 10 วินาที ทุกประเภทที่เปิดอยู่ใช้ **10 วินาที** พร้อมกัน ไม่สามารถกำหนดคนละระยะได้ หากปิด Countdown ก่อนเริ่ม Workout กด Start แล้วเริ่ม Session ทันที

## 9. ปรับหน้าจอและ Pace Units

ไป **Settings → Running Dashboard → Edit Layout** เลือกโหมด Free Run หรือ Interval แล้วเลือก Metric ของแต่ละช่อง สลับลำดับ บันทึก หรือ Reset to Default สามารถ Lock Layout ระหว่างวิ่งเพื่อป้องกันการกดผิด

เปลี่ยนหน่วยใน **Settings → Units**:

| Setting | Default | Other choice |
|---|---|---|
| Distance | km | mile |
| Pace | min/km | min/mi |

การเปลี่ยนหน่วยจะไม่เปลี่ยนข้อมูลระยะทางจริงที่เก็บไว้ เช่น 400m ยังเป็น 400m ในคอร์ทเดิม เพียงแสดงเทียบหน่วยตามที่เลือก

## 10. Pause, Resume, Finish และบันทึก

- **Pause:** หยุดการนับ Active Workout ตามกติกา Workout Engine และพักเสียงที่กำลังจะออก; ระยะทางขณะ Pause ไม่ควรถูกนับเป็นการวิ่งใหม่
- **Resume:** กลับสู่ Step เดิมและเวลาคงเหลือที่ถูกต้อง; ไม่มีเสียง Countdown เก่าถูกเล่นย้อนรวดเดียว
- **Finish:** ยืนยันการจบ Session ก่อนเวลา/ตามกำหนด ตรวจสอบ Distance, Duration, Pace, Splits
- **Save:** เก็บใน SQLite ก่อน หากไม่ออนไลน์ขึ้นสถานะ Pending Sync และส่งเมื่อเครือข่ายกลับมา

อย่า Force Close แอประหว่างวิ่งโดยไม่จำเป็น เพราะระบบปฏิบัติการอาจหยุดการเก็บข้อมูล; Checkpoint ช่วยกู้ข้อมูลที่บันทึกแล้ว แต่ไม่ได้รับประกันว่าช่วงแอปถูกปิดจะถูกบันทึกต่อ

## 11. Activities / History

เข้า **Activities** เพื่อดูผลที่ผ่านมา กดรายการเพื่อดูประเภท วันเวลา Duration Distance Average Pace Laps และ Work/Recovery splits ตามข้อมูลที่บันทึกจริง

สถานะ Sync:

| สถานะ | ความหมาย |
|---|---|
| Saved locally | บันทึกในเครื่องแล้ว |
| Pending sync | รออินเทอร์เน็ต/คิวอัปโหลด |
| Syncing | กำลังส่ง |
| Synced | Cloud ยืนยันการบันทึกแล้ว |
| Failed | อัปโหลดล้มเหลว; ข้อมูลในเครื่องยังอยู่และสามารถ Retry ได้ |

## 12. แชร์ผลเป็นลิงก์ให้โค้ชทางแชท

1. เปิด **Activities → Activity Detail → Share**
2. เลือกสิ่งที่จะแชร์ เช่น เวลา ระยะ Pace และ Interval Splits
3. เลือก **Unlisted Link** และยืนยันการเปิดเผย
4. ถ้า Activity ยังไม่ Sync ให้รอการ Sync หรือกด Retry ก่อน
5. เมื่อสำเร็จ คัดลอกลิงก์ HTTPS จากแอป
6. ส่งลิงก์ใน LINE/Facebook/แชทให้ผู้ดูแล
7. ผู้รับเปิด Summary ผ่านเว็บได้ โดยไม่ต้องติดตั้ง PaceLab
8. หากไม่ต้องการแชร์แล้ว ให้กลับไปกด **Revoke Link**

**ความเป็นส่วนตัว:** Private เป็นค่าเริ่มต้น ผู้ที่มีลิงก์ Unlisted เข้าถึงข้อมูลที่แชร์ได้ ควรหลีกเลี่ยงการเผยแพร่ต่อโดยไม่จำเป็น เส้นทาง GPS และจุดเริ่ม/จบที่ละเอียดจะไม่ถูกแชร์อัตโนมัติ และการ Revoke ไม่สามารถลบภาพหน้าจอที่ผู้รับเคยบันทึกไว้ได้

## 13. แก้ปัญหาเบื้องต้น

| อาการ | วิธีตรวจสอบ |
|---|---|
| GPS Poor/Unavailable | เปิดตำแหน่งแบบ Precise, ออกพื้นที่โล่ง, ตรวจสิทธิ์แอป |
| Pace แสดง `--:--` | รอข้อมูล GPS ที่ผ่านการตรวจสอบ; อย่าสรุปว่า pace เป็น 0 |
| ระยะวิ่งเพี้ยนในสนาม | ใช้ระยะสนามที่วัดจริงเพื่อเปรียบเทียบ และบันทึก Feedback ให้ผู้พัฒนา |
| GPS หยุดหลังล็อกจอ | ตรวจ Background Location, แบตเตอรี่และสิทธิ์ OS; แจ้งรุ่นโทรศัพท์ |
| ไม่ได้ยินเสียง | ตรวจ Media Volume, โหมดเสียง, Bluetooth และ Countdown toggles |
| Interval เหลือเวลาผิด | ตรวจ Plan Preview, Pause/Resume และเวอร์ชันแอป; ส่งผลทดสอบ |
| Login ไม่สำเร็จ | เช็กอินเทอร์เน็ต, Provider, เวอร์ชันแอป, ลองเข้าสู่ระบบใหม่ |
| Sync ค้าง | เช็กเน็ต/สถานะบริการ; Retry และอย่าลบแอปก่อนสำรองข้อมูล |
| เปิด Share Link ไม่ได้ | เช็กว่า Synced แล้ว, link หมดอายุ/ถูกเพิกถอนหรือไม่ |
| iPhone ใช้ APK ไม่ได้ | APK เป็น Android เท่านั้น; ต้องมีช่องทางติดตั้ง iOS โดยเฉพาะ |

## 14. เคล็ดลับก่อนออกวิ่ง

ชาร์จโทรศัพท์พอเพียง อนุญาต GPS ให้ถูกต้อง รอคุณภาพสัญญาณดี ทดสอบเสียงพร้อมหูฟัง ดู Preview โดยเฉพาะวัน Interval และทดลองระยะสั้นหลังอัปเดตแอปทุกครั้ง ความเสถียร GPS/Audio ยังต้องยืนยันกับโทรศัพท์จริงแต่ละรุ่น

## 15. ขอบเขตที่ยังไม่รองรับ

ไม่มีระบบโค้ชแจกคอร์ท ไม่มี AI Coach ไม่มีการวัด Heart Rate โดยไม่มีอุปกรณ์ และไม่มีการรับประกันว่าระบบยังติดตามได้หลัง Force Stop ทุกระบบปฏิบัติการ iOS Native Distribution ยังขึ้นกับข้อกำหนดบัญชี Apple Developer และช่องทางติดตั้ง

## V6.2 (historical) — แจ้งเตือนทุกกิโลเมตร (Auto Kilometer Lap)

### เมื่อวิ่งครบ 1 กิโลเมตร แอปจะแสดงอะไร?

PaceLab ตรวจจับระยะทางสะสมที่ผ่านการตรวจสอบ GPS ครบ **1,000 เมตร** ใน Free Run โดยอัตโนมัติ; ใน Speedwork จะไม่แจ้งครบกิโลเมตร แต่จะสรุปเมื่อจบ Work Set และแสดงสรุป Lap ชั่วคราวโดยไม่หยุดการวิ่ง:

1. **ตัวเลข Hero ใหญ่ที่สุด:** **เพซเฉลี่ยของกิโลเมตรล่าสุด** เช่น `4:42 min/km` สำหรับกิโลเมตรที่ 5 (ไม่ใช่เพซเฉลี่ยทั้งกิจกรรม)
2. **ตัวเลขรองขนาดเล็ก:** **เวลาวิ่งรวม ณ ตอนครบกิโลเมตร** เช่น `24:18`
3. ข้อมูลประกอบ: `KM 5 Completed`, ระยะรวม `5.00 km` และคุณภาพข้อมูลเมื่อจำเป็น

เมื่อเปิดเสียง Auto Lap แอปจะพูด เช่น “กิโลเมตรที่ 5 เพซเฉลี่ย 4 นาที 42 วินาที เวลารวม 24 นาที 18 วินาที” โดยไม่จำเป็นต้องยกมือถือดูหน้าจอ หากกำลังจะเปลี่ยน Work/Recovery แอปให้เสียง Countdown/เปลี่ยนเซ็ตมาก่อนและอาจข้ามคำพูด Auto Lap เพื่อไม่ให้เสียงซ้อนกัน

**วิธีตั้งค่า:** `Settings → Running & Audio → Auto Kilometer Lap` เปิด/ปิด Auto Lap, เสียง Lap และแบนเนอร์สรุปแยกกันได้ ค่าเริ่มต้นแจ้งทุก **1 km** แม้ผู้ใช้เลือกแสดงเพซ `min/mi` ส่วน Countdown ก่อนเริ่มและก่อนจบ Work Set ยังคงใช้ค่ากลางเดียว (ค่าเริ่มต้น 5 วินาที) ไม่ได้เปลี่ยนตาม Auto Lap

**ข้อควรทราบ:** Pace และระยะอาจคลาดเคลื่อนจาก GPS; ถ้าสัญญาณขาดหรือไม่แม่นพอ ระบบอาจแจ้งว่าข้อมูล Lap เป็นค่าประมาณหรือไม่ประกาศเสียง Lap นั้น การ Pause และ Resume ไม่ควรสร้าง Lap ปลอมหรือประกาศซ้ำ

เปิด `Profile → Personal Records` หรือ `Activities → Records` (ตำแหน่งเมนูจริงยืนยันใน UI ก่อนปล่อย) เพื่อดูสถิติ:

แอปจะประเมิน PB จากช่วงระยะ **ต่อเนื่องที่เร็วที่สุด** ในกิจกรรมที่ GPS มีข้อมูลน่าเชื่อถือ เช่น วิ่ง 10K อาจทำ PB 5K ได้ระหว่างทาง โดยไม่ต้องเริ่มที่กิโลเมตรแรก สถิติแสดงเวลา วันที่ และลิงก์ย้อนกลับไปกิจกรรมต้นทาง

- เมื่อยังไม่เคยทำระยะนั้น ให้แสดง `ยังไม่มีสถิติ`
- เมื่อ GPS ขาดหรือไม่น่าเชื่อถือ ระบบจะไม่ยืนยันเป็น PB อัตโนมัติและอาจทำเครื่องหมาย `รอตรวจสอบ`
- หากเพิ่ม PB เก่าด้วยตัวเองในอนาคต ต้องมีป้าย `Manual` แยกจาก PB ที่วัดด้วย GPS
- หากลบกิจกรรมที่เป็นเจ้าของ PB สถิติจะคำนวณใหม่จากกิจกรรมที่เหลือ
- เมื่อ Offline สถิติสามารถอัปเดตในเครื่องก่อน แล้ว Sync เมื่อเชื่อมต่ออินเทอร์เน็ต

**ความเป็นส่วนตัว:** สถิติ PB และเส้นทางเป็นข้อมูลส่วนตัว ไม่แสดงบนลิงก์แชร์โดยอัตโนมัติ เว้นแต่ผู้ใช้เลือกเปิดเผยข้อมูลนั้น การวัดจาก GPS มือถือไม่ใช่การรับรองสถิติแข่งขันอย่างเป็นทางการ

# PaceLab V6.4 — การใช้งานใหม่: Speedwork, PNG และ Analytics (ฉบับรวม)

> หากข้อความ V6.2 ด้านบนระบุให้ Speedwork แจ้งทุกกิโล ให้ยึดข้อกำหนด **V6.3/V6.4 ด้านล่างแทน**: **Free Run แจ้งทุกกิโล; Speedwork แจ้งเมื่อจบ Work Set**. ฟังก์ชันทั้งหมดเป็นคู่มือของแอปที่วางแผนพัฒนา ยังไม่ได้เปิดใช้งานจริง

## 1. เสียงแจ้งเตือนและการดู Splits

**Free Run / Easy / Recovery / Long Run**: เมื่อ GPS ที่ตรวจสอบแล้วครบทุก 1 กิโล แอปแสดงเพซเฉลี่ยของ **กิโลนั้น** เป็นเลขใหญ่ (Hero), เวลารวมอยู่ด้านล่างตัวเล็กกว่า พร้อมเสียง เช่น “กิโลเมตรที่ 5 เพซเฉลี่ย 4 นาที 42 วินาที เวลารวม 24 นาที 18 วินาที” หากเปิด Auto Lap Voice อยู่ เมื่อจบระยะ 5.05 กม. มี 5 ลาปเต็มและ 1 ลาปไม่เต็มช่วงท้าย ตารางสรุปจะสะท้อนทั้งคู่

**Structured Workout / Speedwork**: ไม่มีเสียงหรือ Pop-up แจ้งครบ 1 กม. ระหว่างคอร์ท ค่าเริ่มต้นคือเสียงสรุป **เมื่อจบ Work Set** เช่น “จบเซ็ต 1 ระยะ 720 เมตร เพซเฉลี่ย 4 นาที 10 วินาทีต่อกิโล” จากนั้นเสียงเปลี่ยนเข้าสู่ Recovery ตามกำหนด ระบบยังนับ Warm-up, Recovery และ Cool-down แยกเป็นแต่ละ Step ในผลการวิ่ง แต่ไม่สับสนกับ Work Set

**เสียง Countdown:** ก่อนเริ่ม Workout / ก่อนครบ Work Set / ก่อนเริ่ม Work Set ถัดไปใช้เวลาเดียวกันทั้งหมด (ค่าเริ่มต้น 5 วินาที ปรับ 3/5/10 ได้) และเปิดปิดแต่ละชนิดได้อิสระ ช่วง Countdown หลังเริ่ม Workout ไม่เพิ่มระยะเวลาของเซ็ตเดิม หากเสียงสรุปเซ็ตจะชน Countdown ให้เสียงสัญญาณเปลี่ยนสถานะและ Countdown มาก่อน และไม่เล่นเสียงสรุปที่ช้าเกินไป

## 2. Export PNG สองรูปแบบ (ไม่ต้องใช้อินเทอร์เน็ต)

เปิด `Activities → เลือกกิจกรรม → Export → PNG` แล้วเลือกหนึ่งในสองรูปแบบ:

| แบบ | รูปแบบภาพ | ข้อมูลหลัก |
|---|---|---|
| **Landscape** | การ์ดแนวนอน พื้นเข้ม เส้น Route สีอ่อนทางซ้าย ตัวเลขเรียงแนวนอนทางขวา | Distance, **Average Pace ทั้งกิจกรรม**, Time |
| **Portrait** | การ์ดแนวตั้ง เส้น Route ด้านบน ตัวเลข Distance, Pace, Time เรียงลงมา | Distance, **Average Pace ทั้งกิจกรรม**, Time |

ในหน้า Preview ตรวจสอบหน่วย (`min/km` ค่าเริ่มต้น หรือ `min/mi`), ความถูกต้องของค่า, และเปิด/ปิด Route ก่อน Export เพื่อไม่เผยสถานที่ส่วนตัว หากไม่มี GPS Route ที่ใช้ได้ ระบบแสดงพื้นที่ `Route unavailable` แทน ไม่สร้างเส้นทางเทียม

เลือก **Save/Download PNG** เพื่อบันทึกภาพลงเครื่อง, **Share Image** เพื่อส่ง LINE/แอปอื่นผ่านเมนูแชร์ของโทรศัพท์, หรือ **Copy Image** เพื่อคัดลอกรูปจริงไป Clipboard หาก OS รองรับ หากเครื่องไม่รองรับการคัดลอกรูป ให้ใช้ Save/Share แทน แอปไม่ควรแจ้งว่าคัดลอกสำเร็จหากคัดลอกจริงไม่ได้ **Share Link** เป็นอีกฟังก์ชันแยกต่างหาก ต้องรอ Cloud Sync และสร้างลิงก์ก่อน ไม่เหมือน PNG ที่สร้างจากข้อมูลบนโทรศัพท์ได้

## 3. หน้าสรุปผลละเอียด (Activity Details)

เมื่อกด Finish → Save → เปิด Activities → เลือกกิจกรรม จะมีส่วนต่อไปนี้:

1. **Route & Overview**: แผนที่เส้นทาง, Distance, Elapsed Time, Moving Time, Average Pace และรายละเอียดข้อมูล GPS (ถ้ามี); ทุกค่าต้องมาจากข้อมูลบันทึกจริง
2. **Pace Graph**: กราฟ Pace ตามเวลา/ระยะทาง เห็นช่วงเร็วหรือช้า แสดงหน่วย min/km หรือ min/mi ที่เลือกไว้ ค่าเพซต่ำหมายถึงวิ่งเร็วกว่า
3. **Splits & Comparison**: Free Run แบ่งทุกกิโล พร้อมช่วงท้ายที่ไม่ครบกิโล; Speedwork แบ่งตาม Warm-up, Work Set, Recovery, Cool-down และกราฟเปรียบเทียบเซ็ต ไม่รวม Recovery ในค่าเฉลี่ยเฉพาะ Work
4. **Cadence (รอบขา)**: ค่าเฉลี่ย/สูงสุดและกราฟ `spm` **เมื่อมือถือหรือเซนเซอร์รองรับและข้อมูลเชื่อถือได้**. หากไม่รองรับ แสดง `ไม่มีข้อมูล` ไม่ใช้ GPS/เพซคาดเดารอบขาเอง โดย Cadence เป็นฟีเจอร์ P1 ที่อาจยังไม่พร้อมในรุ่นแรก
5. **Elevation & Gradient (ความสูง/ความชัน)**: กราฟความสูงตามระยะ, Elevation Gain/Loss และความชัน (%) เฉพาะเมื่อข้อมูลแนวดิ่งเชื่อถือได้ หาก GPS สัญญาณไม่ดีให้แสดงความไม่แน่นอนหรือ `ไม่มีข้อมูล` (P1)
6. **Records & Sharing**: สถิติ PB 800m, 1K, 3K, 5K, 10K, Half Marathon (21,097.5m), Marathon (42,195m), Longest Run, ปุ่ม PNG Export และ Share Link ตามสิทธิ์ผู้ใช้

ในเฟส P1 ผู้ใช้จะสามารถแตะเลือกเซ็ต/ลาปหรือช่วงในกราฟให้ตำแหน่งบน Route และกราฟ Pace/Cadence/Elevation ไฮไลต์ช่วงเดียวกันได้เมื่อมีข้อมูลเวลา/ระยะที่เทียบกันได้

## 4. สถานะข้อมูลและข้อจำกัดสำหรับนักกีฬา

- Pace และระยะจาก GPS มือถือเป็นค่าประมาณ ไม่ใช่ผลวัดสนามที่ได้รับการรับรองอย่างเป็นทางการ
- รอบขาจากเซนเซอร์มือถืออาจไม่แม่นเมื่อพกโทรศัพท์ต่างตำแหน่ง และอาจไม่มีข้อมูลบนบางรุ่น
- ความชันจากความสูง GPS ที่แกว่งอาจไม่เหมาะสำหรับการวิเคราะห์เนินช่วงสั้น; แอปควรแสดงคุณภาพการวัด
- ข้อมูลที่ไม่ทราบจริงจะแสดง `— / N/A` ไม่ใช่ศูนย์หรือเลขจำลอง
- PNG ไม่ส่งตำแหน่งไป Cloud โดยอัตโนมัติ ส่วน Web Share Link ให้เลือกข้อมูลที่จะเปิดเผยเอง และเพิกถอนลิงก์ได้
